## 📋 前后端分离部署需要修改的配置

#### 一、前端需要修改内容

### 1. vue.config.js - 修改 publicPath

```javascript
module.exports = defineConfig({

  transpileDependencies: true,

  // 分离部署时改为 '/'，或者 CDN 地址如 'https://cdn.example.com/'

  publicPath: '/',

})
```

### 2. src/router/index.js - 修改路由基础路径

```javascript
const router = createRouter({

  // 分离部署时改为 '/' 或不传参

  history: createWebHistory('/'),

  routes,

});
```

### 3. src/config.js - 修改代理服务器地址

```javascript
export const PROXY_CONFIG = {

    // 改为后端实际部署的地址

    BASE_URL: process.env.VUE_APP_PROXY_URL || 'https://api.yourdomain.com',

    TIMEOUT: 60000,

};
```

------

## 🎯 对比总结

| 配置项                  | 一体化部署              | 分离部署        |
| :---------------------- | :---------------------- | :-------------- |
| `publicPath`            | `/web/`                 | `/` 或 CDN 地址 |
| `createWebHistory()`    | `/web/`                 | `/`             |
| `PROXY_CONFIG.BASE_URL` | `http://localhost:8082` | 后端实际域名    |

------

## 💡 建议：使用环境变量

你可以创建 .env 文件来区分不同环境：

```
.env.development (本地开发一体化)：
```

```
VUE_APP_PROXY_URL=http://localhost:8082

VUE_APP_PUBLIC_PATH=/web/
```

```
.env.production  (分离部署)：
```

```
VUE_APP_PROXY_URL=https://api.yourdomain.com

VUE_APP_PUBLIC_PATH=/
```

然后在 vue.config.js 中使用：

```javascript
publicPath: process.env.VUE_APP_PUBLIC_PATH || '/'
```

这样**打包时根据环境自动选择配置**，无需手动修改代码！

#### 二、后端修改内容

前后端分离部署时，后端不再需要托管前端静态文件，可以删除以下代码：

## Node.js (main.js) - 可删除的代码

**第 339-346 行**（静态资源和 SPA Fallback）：

```javascript
// ❌ 可删除

// 静态资源 (SPA 支持)
app.use("/web", express.static("webPro"));


// SPA Fallback: /web 下所有未匹配静态文件的路径都返回 index.html
app.use("/web", (req, res, next) => {

    res.sendFile(path.join(__dirname, "webPro", "index.html"));

});
```

同时，**第 311-312 行**的 /web 路径跳过检查也可以删除：

```javascript
// ❌ 可删除这行

if (req.path.startsWith("/web")) return next();
```

## Python (main.py) - 可删除的代码

**第 327-354 行**（整个静态资源部分）：

```python
# ❌ 可删除

# ---------------------------

# 9. 静态资源 (SPA 支持)

# ---------------------------

WEB_ROOT = os.path.join(os.path.dirname(os.path.abspath(__file__)), "webPro")



@app.route("/web")

@app.route("/web/")

def serve_web_index():

    """提供前端首页"""

    from flask import send_from_directory

    return send_from_directory(WEB_ROOT, "index.html")



@app.route("/web/<path:filename>")

def serve_static(filename):

    """提供静态资源，支持 SPA fallback"""

    from flask import send_from_directory

    file_path = os.path.join(WEB_ROOT, filename)

    

    if os.path.isfile(file_path):

        return send_from_directory(WEB_ROOT, filename)

    

    return send_from_directory(WEB_ROOT, "index.html")
```
